
# ASE Scientific Simulation & AI Evaluation

## Project Overview
A reproducible scientific computing project using Python
and the Atomic Simulation Environment (ASE).

This project investigates the energy-volume relationship
of face-centered cubic (FCC) copper using the EMT calculator.

## Objectives
- Build an FCC copper crystal structure.
- Calculate potential energy at different volumes.
- Estimate equilibrium volume and lattice parameter.
- Calculate the bulk modulus.
- Validate scientific results.
- Develop an AI scientific reasoning benchmark.

## Technologies
- Python
- Atomic Simulation Environment (ASE)
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Methodology
1. Construct an FCC copper crystal.
2. Attach the ASE EMT calculator.
3. Evaluate energy across lattice parameters.
4. Fit an equation of state.
5. Estimate equilibrium properties.
6. Save and validate numerical results.

## Results
The simulation generates:
- Energy-volume data (CSV)
- Scientific visualization (PNG)
- Simulation summary (JSON)

The results are predictions from the EMT model,
not experimental measurements.

## AI Evaluation
The next stage will develop scientifically verifiable
questions and evaluation criteria using simulation outputs.
